# UX issue register

This register preserves findings from the post-V5 UX review. It is intentionally separate from
the focused deadline, guidance, transaction-feedback, and clean-clone work. An item remains open
until it has been implemented and verified in a later visual-cleanup pass.

| Finding | Current status | Next verification |
| --- | --- | --- |

| Some action labels wrap or produce uneven button rows | Open | Check card and dialog actions at 375px and increased text size |

| Stale form values may still appear outside the repaired draft lifecycle | Open | Audit every form type and completed-action cleanup independently |
| Supplier invitations do not explain the review outcome clearly enough | Open | Test named supplier, outsider, accepted, and declined states |

| Role-specific notifications remain incomplete | Open | Map buyer, organizer, supplier, and refund eligibility to each surface |
| Homepage text can overlap at some widths or text-size settings | Open | Check 320–1440px, 200% zoom, and browser text enlargement |

The current focused pass does not claim to resolve these items.
